# Prompt AI — Tài nguyên hình ảnh

`img/` lưu hình minh họa và ảnh chụp giao diện được dùng trong README hoặc tài liệu dự án.

- Giữ nguyên tên file hiện có nếu README đang tham chiếu tới chúng.
- Với ảnh mới, chọn tên mô tả ngắn, định dạng phù hợp và cập nhật liên kết Markdown nơi sử dụng.
- Không xem ảnh chụp giao diện như bằng chứng đầy đủ về hành vi hiện tại; kiểm tra ứng dụng nếu cần xác nhận.
- Không thêm hình chứa thông tin bí mật hoặc dữ liệu người dùng thật.

Khi hoàn tất, ghi rõ ảnh nào được thêm/thay và tài liệu nào tham chiếu ảnh đó.
